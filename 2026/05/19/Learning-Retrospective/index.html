前言

学了不少东西，东一块西一块的，趁这个机会整理一下自己到底学了什么，也梳理下以后的方向。这篇算是第二篇正经博客，之前那篇 First Blog 随便写的，不用管它。

C/C++：从语法到 STL，再到啃不动的书

C/C++ 是最早系统学的语言，从最基本的语法（指针、内存管理、结构体、类）到 STL 容器（vector、map、set、queue、stack、priority_queue 这些）都过了一遍。STL 不止容器，还有 <algorithm> 里的 sort、lower_bound、next_permutation 等等，刷题常用；<string> 和 <sstream> 做字符串处理也很方便；<functional> 配合 lambda 写起来很顺手。

书也读了几本：

  • 《C++ Primer》：经典教材，跟着过了语法和基础特性，但老实说没完全消化，以后当手册翻。
  • 《Effective C++》：Scott Meyers 那本，讲了 55 个改善 C++ 编程的建议。难，真的难看懂，很多条款涉及模板、继承体系、异常安全这些深层机制，当时功力不够，只能先混个眼熟。
  • 《数据结构与算法分析（C 语言描述）》：这本应该是四大件之一了，也是最感兴趣的一本。树（AVL、红黑树、B 树），图（邻接表/邻接矩阵、拓扑排序、最短路径），还有各种散列和堆，深度优先（DFS）和广度优先（BFS）这些算法，写起来很有意思。
  • 《算法导论》（CLRS）：砖头书，没通读，当参考书翻了一些章节，主要还是配合数据结构那本一起看。

Python：从脚本小子到安全工具链

Python 语法学得比较快，算是上手成本最低的语言。真正用起来是学安全之后：

爬虫 & 信息搜集

  • **requests**：发 HTTP 请求，模拟登录、抓页面、构造 payload。
  • **beautifulsoup4**：解析 HTML，提取表单、链接、隐藏字段。
  • **re**：正则匹配，从响应里抠 flag、找敏感信息。

GUI 开发

用 tkinter 和 PyQt 写过小工具，给一些安全脚本套个图形界面，不用每次敲命令行。

PWN 方向

Python + pwntools 是标配。from pwn import * 一行搞定远程连接、构造 payload、格式化和调试输出。libcsearch 之类的库用来查 libc 版本和偏移，做 ret2libc、one_gadget 都需要。

Java：基本语法 + Android 逆向起步

Java 学了基本语法（面向对象、集合框架、IO），主要用得上的场景是 Android 逆向。碰到过安卓 Java 层的逆向题目，用 jadx 反编译 APK 看源码、分析逻辑、找加密函数入口。对 Smali 也有初步了解。

Java 的语法和 C++ 接近但又更干净（没有指针那套），做项目比 C++ 省心很多，之后打算用 Java 做点实际的东西。

汇编：底层的语言

汇编属于必须掌握但不需要精通的程度。x86/x64 指令集基本能看懂，mov、lea、call、ret、push、pop 这些，配合 call convention（cdecl、stdcall、fastcall、System V AMD64 ABI）看反汇编代码。对 PWN 题来说，读汇编是基本功，特别是分析栈帧布局、找返回地址偏移。

其他语言：广撒网，浅尝辄止

语言 掌握程度 说明
Rust 略有涉猎 安全圈热门，owner 机制很特别
Go 略有涉猎 并发模型简洁，写工具很合适
HTML/CSS 略有涉猎 懂基础能写页面，也了解 XSS 需要
JavaScript 略有涉猎 前端相关，XSS 核心
PHP 略有涉猎 审计过简单代码，文件上传也涉及

操作系统 & Linux

操作系统方面基本专注 Linux，毕竟大部分工具链和安全实验都在 Linux 下跑。

  • **pwn.college**：ASU 的开源 CTF 平台，从 Linux 基础到高级二进制漏洞利用，循序渐进，质量很高。在上面刷了不少模块。
  • 网络测试：用过 Wireshark 抓包分析流量，Maltego 做信息关联和 OSCINT 侦察。
  • 二进制调试工具链：
    • pwndbg：GDB 的 PWN 增强插件，heap 可视化、context 自动显示、ROPgadget 查找，日用必备。
    • GDB：原版 GNU Debugger，配合 gef、peda 也用过。
    • objdump / readelf：静态分析二进制文件结构和反汇编。
    • checksec：检查二进制保护机制（PIE、NX、Canary、RELRO、FORTIFY）。

安全方向：杂七杂八的经验

Web 安全

  • SQL 注入：在 SQL-Lab 平台逐关复现过，从 Union 注入、报错注入、布尔盲注到时间盲注，再到二次注入、堆叠注入，基本把常见类型过了一遍。
  • Burp Suite：爆破、抓包改包、Intruder 模块配合字典跑弱口令。
  • Apache：简单了解过 Apache 配置和常见漏洞（目录遍历、文件解析漏洞）。

逆向工程（Reverse）

  • 花指令：反汇编干扰，通过修改跳转绕过。
  • 平铺（代码平坦化）：控制流混淆，用符号执行或动调追踪还原逻辑。
  • 加解密算法识别：常见的 base64、AES、DES、RC4、TEA、XXTEA，能识别特征并逆向还原（或写出解密脚本）。

PWN / 二进制漏洞利用

  • 栈溢出：最经典的攻击面，覆盖返回地址 → ret2text → ret2shellcode → ret2libc → ret2csu → ret2dlresolve，逐渐深入。
  • 堆溢出：ptmalloc2 的内存管理机制（bin、tcache、fastbin），use after free、double free、off-by-one、unsorted bin attack、tcache poisoning 等利用手法。
  • 内核：目前还在入门阶段，了解 LKM、漏洞触发、commit_creds(prepare_kernel_cred(0)) 这个经典提权链，还有 KPTI、SMEP/SMAP 这些缓解机制。

以后的方向

学了不少，但很多都是蜻蜓点水。接下来想重点深入：

  1. Web 安全：把 XSS（反射型、存储型、DOM 型）吃透，CSP 绕过也要研究。Linux 渗透测试的完整流程从信息收集到提权。
  2. 逆向：Android 逆向（so 层 Native 逆向，Frida hook），macOS/iOS 逆向有兴趣但不急。
  3. 二进制：PWN 往内核方向深入，堆利用再巩固，浏览器漏洞方向也可以了解。
  4. 开发：用 Java 做一两个完整的项目出来，实战练手。Go 写安全工具作为辅助语言。

路还很长，坚持写博客记录吧。
