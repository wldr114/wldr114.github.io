Git 工作流实战

操作流程

1. 克隆仓库到本地

2. 创建并切换到新分支

3. 查看改动

4. 暂存所有改动

5. 提交改动

6. 推送到远程仓库

一些疑问：git push -f 危不危险？

git push -f（即 git push --force）会强行用本地的提交历史覆盖远程分支……

今日总结

学习了 Git 的基本工作流clone → 建分支 → 改代码 → diff 检查 → add 暂存 → commit 提交 → push 推送，这是日常开发的标准流程

以后坚持每天写代码、写博客，慢慢积累
